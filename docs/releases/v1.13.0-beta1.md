# Release v1.13.0 Beta 1 (2026-11-17)

This release includes all changes from [v1.12.0 Beta 2](v1.12.0-beta2.md), plus the following.

It is a security and dependency maintenance release. Test cases, discovery models, configuration, and report and configuration export are unchanged.

## Security

- Rebuilt the Docker image (`linux/amd64` and `linux/arm64`) on Go 1.26 (previously Go 1.21) and `alpine:3.24.4` (previously `alpine:3.24.3`).
- Upgraded vulnerable Go dependencies, including:

  | Dependency | From | To |
  | --- | --- | --- |
  | `github.com/labstack/echo/v4` | 4.11.3 | 4.16.4 |
  | `github.com/getkin/kin-openapi` | 0.128.0 | 0.149.0 |
  | `github.com/lestrrat-go/jwx` | 1.0.2 | 1.2.29 |
  | `github.com/golang-jwt/jwt/v5` | 5.2.0 | 5.2.2 |
  | `github.com/gorilla/websocket` | 1.4.1 | 1.5.3 |
  | `golang.org/x/net` | 0.25.0 | 0.62.0 |
  | `golang.org/x/crypto` | 0.23.0 | 0.59.0 |
  | `github.com/sirupsen/logrus` | 1.4.0 | 1.8.3 |

- Removed `github.com/refraction-networking/utls`. The TLS version check used when a proxy is configured now uses the Go standard library `crypto/tls`.
- The tool's HTTPS listener now requires TLS 1.2 or later and no longer offers static-RSA key exchange or 3DES cipher suites. ECDHE cipher suites, including ECDHE-CBC, are still offered.
- Removed the `git`, `wget` and `coreutils` packages from the Docker image. BusyBox still provides the common commands, including `ls`, `cp`, `sort` and `wget`. `bash`, `curl`, `emacs`, `jq`, `openssl`, `tree` and `vim` are still included.

## Changed

- Building from source now requires Go 1.26.11 or later. With the default `GOTOOLCHAIN=auto`, `go` downloads the required toolchain automatically.
- `/favicon.ico` is now served with the content type `image/vnd.microsoft.icon` (previously `image/x-icon`).
- WebSocket handshakes with an invalid `Sec-WebSocket-Key` are now rejected with `400`. Valid clients are unaffected.
- A few error and log messages that include text containing `%` now show that text literally instead of treating it as a format directive.

## Fixed

- Fixed a possible crash (`fatal error: concurrent map writes`) while acquiring consents. Concurrent consent workers wrote to the shared run context at the same time. Each worker now returns its client access token, and the tokens are merged once all workers have finished.
- Fixed a data race in the response property collector that could crash the tool or produce inconsistent collected-property data when several requests were processed at the same time.

## Known limitations

These findings are reported by Docker Scout for the image. They are **deferred**; they are not resolved or suppressed in this release.

| Component | Advisory | Severity | Status |
| --- | --- | --- | --- |
| musl libc (Alpine) `1.2.6-r3` | CVE-2026-107891 | High | Scout reports a fix in `1.2.6-r6`, which is not available in the stable Alpine 3.24 repository. Alpine's own security database lists the installed `1.2.6-r3` as fixed. |
| `github.com/labstack/echo/v4` `4.16.4` | CVE-2026-118651 (GO-2026-6875), CVE-2026-118653 (GO-2026-6872) | Medium | No Echo v4 fix is available. The affected proxy and rate-limiter middleware are not used by the tool. Fixing this needs a migration to Echo v5, which is out of scope for this release. |
| OpenSSL command-line tool (`openssl` `3.5.9-r0`) | CVE-2026-88822, CVE-2026-88823, CVE-2026-95691, CVE-2026-95692, CVE-2026-107496 | Unrated | The `openssl` command remains in the image and is not invoked by the tool. The fixed Alpine package (`3.5.9-r1`) is not yet available for Alpine 3.24. |

The investigation into client-side TLS certificate verification (`InsecureSkipVerify`) is also deferred. It is tracked in [#357](https://github.com/OpenBankingUK/conformance-suite/pull/357).
